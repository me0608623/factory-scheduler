# 現場報工回寫與補排（2026-09-30）

## 目標

排程不能只保存「原本打算做什麼」。現場以開工、累計件數、完工回報實績；完工少做的件數重新成為未排量，下一次人工或自動重排補足，同時保留原方塊的原定件數供計畫／實績比較。

## 本次完成

- 工單抽屜：保留綠／黃／紅／灰交期燈號，另顯示未做、進行中、已有回報、已完成。點工單仍只高亮該單方塊。
- 人員、產量、備忘：沿用既有抽屜。產量沒有回報時仍顯示「尚未回報」，不補假數字。
- 員工現場回報：員工角色只看自己的目前工作與同一設備的下一件；進入工作後固定顯示「開工／做了幾件／完工」三個大按鈕。
- 失敗回饋：未知網路或伺服器失敗明確顯示「沒存到」，保留同一 request id 供重試，避免重複計量。
- 今日現場班表：Excel 視窗新增列印入口；列印時隱藏導覽、彈窗、抽屜與聊天室，只留下排程表並採橫向紙張。
- 實績回寫：完工方塊以 `qtyDone` 計入完成量；未完工／進行中方塊仍以原定件數保留。完工短少會回到尚待排量。
- OR-Tools：前端快照新增 `work_execution`；求解器保留已回報的原方塊，再只排缺少件數。
- 跨站物料：前站完工後以實際件數判斷交接與累積產量，不能把未做出的原定件數交給後站。
- 資料庫：`0029_execution_shortfall_replan.sql` 讓手動儲存與方案套用以「實際完成＋待做」驗證總量及跨站流量。
