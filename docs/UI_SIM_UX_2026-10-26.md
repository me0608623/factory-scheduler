# Real SIM UI follow-up — 2026-10-26

## Mobile zoom controls stay available

Proactive inspection of the existing actual SIM snapshot reproduced a mobile interaction defect: expand the day board's **More** tools and press zoom-in. The scale changes from 100% to 125%, but More immediately collapses and focus falls to `BODY`. Toggling wheel zoom has the same result. A user cannot continue adjusting the scale without reopening the tools.

`render()` replaces `#app.innerHTML`, losing the native `details.open` state. Existing zoom focus restoration then targets a hidden button. The fix captures and restores that boolean at the shared render boundary, covering both `applyZoom()` and the direct render in wheel-toggle. It adds no persisted preference, data operation, event handler, or public API. First load remains closed; closing remains respected; leaving the day tools for another view resets the disclosure on return.

Desktop controls were already visible despite the closed native disclosure. This is a mobile defect with desktop regression coverage, not a claim that desktop zoom was broken.
