## 事前核對與安全界線

1. 核對 worktree、最新提交、CI、實際線上 bundle 與其他 modifier/deploy。重疊時僅只讀，不另開一份修改或部署。
2. 核對網站確為 staging，讀取的服務確為 `fkefarcwadvyqqjcjxvp`，不得只靠頁面標題辨識環境。不要公開 key、token、請求本文、身份資料或整份快照。
3. 使用現有測試資料。12 人、8 資源、20 單、103 段是原始匯入基準，另有 demo 與後續測試變更，不能要求現況總數等於基準。禁止重匯、重置或刪除資料來湊數。
4. 先記錄工廠、日期、可見方塊、目前同步狀態和目標測試方塊的原機台/時段。今天空表時檢查其他機台提示、日期與工廠，不自動產生示範資料、不把尚未載入當資料遺失。
5. 沿用可用登入，不猜密碼、讀舊 SQL 密碼、改密碼或變更既有角色/個人功能授權。確認兩個實際不同的測試身份與既有角色；同一帳號兩頁籤不是跨帳戶證據。需要本人登入時留下清楚入口，繼續其他安全項目；寄信/建立帳號依最新直接人類授權，不把過時「未同意」文字當現況。
6. 只移動已確認的合成測試方塊，不操作 demo 或未知來源資料。寫入前確認無別人正在改目標、沒有報工鎖、保存前後基準；如出現衝突或未知儲存結果，停止該筆寫入，不反覆重送、不整份快照回灌。
7. Render hook secret 是可選的維運備援，不是功能驗收前提。自動部署問題依實際部署紀錄查證，不新增付費資源，不因文件變更重部署 runtime。

## A 登入與既有角色

1. 在桌面尺寸與手機尺寸各載入 staging。記錄工廠、日期、方塊與抽屜位置；手機尺寸模擬不算真機 Safari。手機與桌面選相同日期/工廠後應看到一致的方塊資料。
2. 依已登入身份的既有權限，核對允許操作可進入、禁止操作不可執行。不要為驗收切換帳號角色或權限開關。權限選單隱藏只證明 UI 閘門；後端拒絕須另有真實測試身份的拒絕且資料未變證據，不能用 boss 操作或本機 mock 代替。
3. 第二身份不可用時，只把跨帳戶/不同角色項目標阻擋，不阻止同帳戶桌面/手機尺寸、預覽取消、可觸達性、匯出與隔離邏輯測試。

## B 拖曳預覽與真正套用

1. 取指定合成測試方塊，拖到合法空閒機台/時段。確認預覽清楚顯示變更；按取消後原方塊、資料與儲存基準不變，其他裝置也不應看到任何已提交變更。
2. 再次拖曳並按「用這套」。記錄預覽差異、實際成功/失敗回饋、目標方塊最終位置與非目標方塊不變；在獨立頁面重新讀取確認確已儲存。這才是排程套用驗收，按鈕可點或 toast 不算。
3. 手機尺寸檢查預覽與取消/套用控制可見且可操作、不被抽屜/鍵盤遮住，觸控區至少 44px；真手機拖曳與真雙端驗收另記。
4. 如需把合成測試方塊移回原位，只在確認沒有遠端新變更、沒有報工/鎖定且目前位置仍是本輪寫入時，以一般預覽/套用流程移回。否則保留現況與操作紀錄，不強制還原、不刪資料。

## C 自動同步 三條路徑分開驗收

兩端先開同日期/工廠，接收端無草稿/預覽/拖曳/在途或失敗寫入。記錄發送與接收時間、兩端版本/方塊欄位、是否人工更新，以及接收端觀測到的訂閱/補讀路徑。第二身份未可用時可先驗同帳戶獨立頁面，但跨帳戶項目仍未驗證。

1. **Realtime 自動更新**：接收端不按更新、不重新載入、不切頁。發送端完成一筆合成排程變更，接收端實際自動出現同筆變更且有訂閱事件/讀取證據才 PASS。連線徽章或 ticket 回覆不作通過條件；無路徑證據時僅記「自動更新已觀測，來源未確認」。
2. **中斷期間輪詢備援**：即時中斷時，接收端仍不人工更新；以目前程式的 60 秒輪詢加 debounce 設本輪 75 秒觀察上限。方塊實際更新、沒有重複寫入才可記備援 PASS。這不代表 Realtime 恢復；到時未更新記 FAIL 或依實際守門原因記 deferred，不自行延長直到碰巧綠燈。
3. **手動更新**：另外操作更新按鈕，確認資料更新。只記手動更新 PASS，不能填入前兩項。
4. **草稿保護與補讀恢復**：接收端保留未存草稿/預覽時發送端更新，草稿不可被補讀覆蓋；取消草稿後再觀察是否安全補讀。隔離函式/SQL測試與真雲端結果分列。

## D 斷線 衝突 報工與復原

1. 只對隔離測試站的測試方塊離線修改/儲存。確認明確未存回饋、重試入口、離開提醒與登出保護。瀏覽器網路模擬不等於真手機飛航；測完解除模擬。離開提示只取消，不為測試丟棄草稿。
2. 恢復連線後依 UI 明確重試一次，獨立讀取確認位置/進度與版本一致，不以綠徽章代替資料核對。未知結果先核對，不盲目新建 request 或連點。
3. 兩端持同一舊基準改同一測試方塊，先後保存，實測後者收到衝突且不把被拒絕草稿復活/覆蓋新版。回讀確認接受者資料保留；本機合成衝突不能充作真雲端兩帳戶證據。
4. 如測報工，只對本輪已明確選定的合成測試段，記錄開始/件數的原值與新值、進度鎖與兩端回讀；不要以刪除報工或解鎖回退清理。
5. **復原安全**：接收遠端新版後舊 undo 應清除或失效；按舊復原不得回寫或覆蓋遠端排程/報工。清除舊 undo 的提示/停用是安全結果，不要求一定還原舊拖動。遠端補讀後新產生的本機修改可另測正常復原。

## E 日常操作與效能

1. 不匯入資料，直接使用既有測試方塊切日期、工廠、日/週，核對顯示內容、互相鑽取與無白屏。記實際資料量與耗時；舊 1,980 段基準不能當作目前手機或線上性能結果。
2. 下載彩色排程 Excel，實際開啟/解析檔案，核對工作表、日期、方塊內容與非空資料；下載事件成功不代表檔案正確。產物留受限本機，不公開雲端資料。
3. 實際進入列印預覽並取消，不送印；封鎖彈出視窗時需明確提示且頁面可繼續操作。兩種路徑分列，不以一條通過代替另一條。
