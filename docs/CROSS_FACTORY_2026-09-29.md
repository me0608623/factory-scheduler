# 跨廠加工第一版與可編輯工序／產品

本輪是開發版實作，未匯入使用者貼上的歷史加工清單，也未推定其年份。沒有寫正式 Supabase、部署 Render、合併或推送 main。migration 0023 僅在測試資料庫驗證。

## 操作入口與能力

頂部「跨廠加工」管理來源廠、加工廠、回收廠、加工單號、文字品號、總量、急用數量、通知日、預計交料、回廠／急用期限、工作內容與備註。總量／日期可留空待確認；急用量是總量的子集。加工單號與品號不同，同一品號可多張加工單。

需求只有老闆／組長可編輯；其他成員唯讀。啟用、暫停或取消保留歷史；不提供刪單。已流轉的品號、廠別不可改。

每張單可建立多批次，所有批次計畫量不超過總需求。每批次登記本次增量與台灣當地實際時間：來源廠交出、加工廠點收、加工完成（良品／不良）、送回、回收廠點收（合格／差異）。先預覽，取消不寫入，確認才保存。未送不能點收；未點收不能完成；送回不能超過完成良品；點收合格＋差異不能超過送回。實際事件不能填未來時間，順序按實際時間及同分鐘登錄順序重驗。

流轉是材料的真實紀錄，不自動生成產能、不直接把排班標為已完成。保存後事件不能刪改；本版尚無撤銷、更正單或返工流程。錯誤紀錄需要經後續受控更正功能處理，不可直接重寫。

## 與人工／設備工作連結

批次可開「連結人工／設備排班」，沿用一般工作的人員、工位與時間預覽。亦可在一般工作選批次及「加工廠加工」或「回廠點收後工作」。加工階段須使用加工單指定且屬於加工廠的工作；回廠後階段須屬於回收廠。跨廠計畫件數必填，同批次、同階段、同工作累計不得超過批次量；不同工序不重複累計原料需求。

計畫可以早於到料，明確標示預排／缺料，沒有假造點收。料況以該排班開始時已登記的實際點收為準，扣除同工作較早預排占用；同時開始時以排班 ID 穩定分配，缺量明確提示。加工階段另保守扣除已登記的不良及送回量，避免重用已離廠材料；尚未與逐段實耗對帳，因此可能偏保守，不是完整庫存可用量。回廠後工作只認合格點收量。不良品不增加回廠可用量。

仍可拖曳、拉伸，放開先預覽；連結、件數、占用與料況會重驗。OR-Tools 仍只把一般工作當固定人機占用，沒有自動跨廠派工、運送／點收時間最佳化，也不會自動將原生生產工單與此材料台帳同步。

## 提示與介面

- 清單顯示總量、到料、完成、回廠合格、急用缺口、回廠期限、狀態與缺漏資訊。
- 詳情顯示批次五步數量、良品／不良／點收差異、相關排班與流轉歷史。
- 未足量點收的方塊顯示「待料」及加工單號。預覽與詳情顯示缺量原因。
- 回廠、急用未滿且期限已過時提示逾期；已結案但實際回廠晚於期限時仍保留逾期提示。
- 預排工作日晚於要求回廠期限時另提示，明確未包含運送及點收時間，不冒充完整預測。

## 修正示範選項限制

設備設定的工序改成自由文字，提供既有名稱建議而非固定五個選項。產品工序可新增產品／品號、編輯名稱、自訂工序與廠別；新增工序速率預設未核定（0），須明確填正值才可存。示範產品明確標示不是 1023 已核定結果。

已有工單的產品在 UI 只允許改名稱，工序／產能變更需新增版本，避免重解讀原排程。這是 UI 保護，不是本輪新增的全資料庫產品版本規則。

設備可選自行建立的加工產品，並有產品設定入口；未保存的設備表單不直接丟棄。產品與模具不再混稱：本版仍沒有獨立模具庫、共用模具占用或換模排程。

## 資料與限制

加法 migration 0023：跨廠加工表、一般工作批次／階段欄、RLS 唯讀、角色限定 RPC、版本鎖、稽核、即時推送、來源與批次連結重驗。台帳與排班分開保存，不允許混合批次寫入導致半份資料。數量／時間／連結驗證失敗交易全回滾；過期版本拒絕；直接寫入與 TRUNCATE 權限關閉。快照與試排情境保留台帳，台帳變更令舊情境過期。

每張單最多 200 批次、2,000 個事件；本版合計最多 1,000 張單、5,000 個事件及約 2 MB JSON。超過時拒絕而非截斷，需後續封存／分頁擴充。加工單本版使用可設定的文字品號，不強制關聯原生產品／工單；原料多用途分配、退料、返工、更正、庫存倉位、批次追溯報表與電子通知未加入。

## 驗證

單元及 PostgreSQL 相容測試涵蓋需求缺漏、急用子集、分批五步、不良與差異、超交、未點收完成、倒序時間、未來事件、不可竄改、重送、同批次排班量、跨廠資格、原料提示、回廠合格提示、實際逾期與預排風險、本機交易拒絕、版本／角色／直接寫入／TRUNCATE、SQL 全回滾與自訂產品工序雲端保存。

瀏覽器本機測試使用明確 TEST-* 虛構資料：建立二廠測試人員／人工工作、100 件需求／急用 20／第一批 60，9/30 人工預排 20 件顯示待料；未點收完成被拒；交料預覽取消維持 0；確認交出 30、點收 20、完成 20、送回 20、回廠合格 20，急用缺口消失。重新整理仍見台帳及批次排班。自訂 TEST-加工品001／測試去毛邊／z1 設備可保存，未填核定速率時被拒。

開發初期熱更新測試曾因存檔載入檢查位置錯誤重建本機示範測試班表，當輪即修正；正式雲端與原始 Excel 未觸碰。新增本機保存／拒絕後重讀測試防止再發。瀏覽器測試頁保留 TEST-* 範例，不代表實際 1023 正式排程。

完整回歸：前端／資料層 78 項全通過；資料庫 168 項全通過（包含 0023 migration）；排程服務 95 項全通過；Vite 正式建置成功。最終文案修正後另重跑跨廠 10 項及建置。瀏覽器主控台沒有錯誤／警告。

仍有既有 ExcelJS 載入套件超過 500 kB 建置提醒，以及 Starlette/httpx 測試介面的棄用提醒。未增加費用或修改執行環境。
