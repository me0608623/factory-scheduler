# 排程主畫面覆蓋層線框

這份文件只確認資訊架構與互動，尚未修改正式前端。

## 不可改變的骨架

- 主畫面始終是「機台 × 時間」排程甘特表，不改成儀表板。
- 桌面採左側大圖示導覽與 440px 右側抽屜。
- 手機採底部大圖示導覽與約 70% 高的底部面板。
- 抽屜開啟時不切換整頁；日期、廠別、班表捲動位置不變。
- 再點同一入口或按關閉即可收回。
- 僅初次資料核對可以使用全螢幕步驟；結束後返回班表。
- 核對未完成時可看今天的班表或空表，但自動排班與故障重排停用。

## 六個主要入口

1. 今天：收回所有覆蓋層，回到班表。
2. 工單：交期燈號、未完成／會晚／今日要交；點工單高亮班表色塊。
3. 人：今日缺席、個人月曆、請假詢問核准／駁回。
4. 產量：今日計畫總件數、各機台計畫與實際回報；無回報明示「尚未回報」。
5. 備忘：連結人員或機台的一句話便利貼，可釘選。
6. 更多：低頻設定與匯出，不放在班表上方形成文字按鈕列。

## 狀態規則

- 請假「詢問中」不得寫入正式缺勤，也不得觸發自動重排。
- 灰色工單表示資料不足，不代表準時或逾期。
- 產量只顯示真實回報；缺值不得以 0 或推算值替代。
- 開啟工單、人、產量或備忘時，班表維持可見並高亮其關聯色塊。
