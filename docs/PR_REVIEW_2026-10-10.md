## Findings requiring changes before merge

### #10 — P1: note is lost when changing color

In the row-mark dialog, enter `保留這句 QA`, then click red. The textarea becomes empty because `mk-color` changes only `draft.c` and `renderModal()` reconstructs the note from stale `draft.n`. Capture the current note before rerendering and test this actual sequence.

### #10 — P2: business and mark CSS classes concatenate

`markRowAttrs().cls` is trimmed, while shortage/transfer row renderers concatenate it directly with business-state text. `archived` + `mk-y` produces `archivedmk-y`; similarly `returnedmk-r`. Both the original status selector and mark selector fail. Join an array of class tokens with spaces and cover marked returned/archived/cancelled rows.

### #10 — P2: missing time becomes midnight

`timeVal(null, null)` returns 0 because unary plus converts null to zero. Blank work-log hours therefore sort as 00:00 instead of remaining last in either direction. Explicitly normalize missing components and test asc/desc with blanks.

### #7 — P2: pinned sibling exempts movable short piece

Same operation: 08:00–09:00 pinned, 09:10–09:20 unpinned. Direct execution of the PR's switching.py returns short_necessary=1 and short_avoidable=0 because `any(p.pinned)` covers the entire operation. Classify the short piece's own constraints rather than exempting all sibling pieces.

### #7 — P2: staggered simultaneous tending counted as switching

Same employee with capacity two: A=08:00–10:00 and B=08:10–10:10. Direct execution returns employee_switches=1 although these are overlapping parallel assignments. Equal-start deduplication does not cover general parallel tending. Use interval-aware logic and test input-order invariance.

The objective also measures adjacent stages of the same order, whereas the metric counts adjacent work on a resource. The PR does not directly penalize boundary short pieces; preserve that distinction in documentation and any displayed claims.
